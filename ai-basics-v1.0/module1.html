What is a token?

When you chat with an AI, it doesn’t read words the way you do. It reads tokens. Let’s see what that means.

Why this matters

Tokens are how the AI world counts things. Two big ideas depend on them: cost and speed.

Cost. AI companies charge by the token. You pay for the tokens you send in and for the tokens the AI writes back. More tokens, bigger bill.

Speed. An AI writes its answer one token at a time. Its speed is measured in tokens per second - the number of tokens it can generate in one second.

Does the AI remember you?

An AI model doesn't have memory, but it still knows what you said in past messages. Let’s see what’s really going on.

Step 1: The whole chat is sent every time

Each time you send a new message, all your old messages are sent with it. Before answering, the AI reads all messages from the oldest to the newest. The old messages are called the chat history.

Step 2: The AI can only read so much

The AI can only take in a limited amount of text at once. This limit is called the context window, and it’s measured in tokens. In this demo the window is tiny (just 40 tokens) so you can see what happens when a chat gets too long.

Why this matters

Memory is an illusion. The AI receives the entire chat history along with every new message.

The cost per request keeps increasing. This is because the number of tokens in the chat history keeps increasing. Also, the AI may take longer to respond when the chat history gets very large.

Old details get lost. In a very long chat, early messages can get deleted. This can confuse the AI.

The yellow line is the system message. In most chat apps you can’t see it, but the AI always reads it first. The AI is trained to follow the instructions given in the system message.

Why this matters

One AI, many jobs. Companies use system messages to turn the same AI model into a homework helper, a shop assistant or a game character.

It comes first, every time. The system message sits at the top of the chat history, so the AI reads it again with every message you send.

It uses tokens. The entire conversation history is sent to the AI with every new message. The system message is included in this history. A long system message takes up room in the context window and adds to the cost.

Thinking before answering

Some AI models can “think” before they answer. They are called "Reasoning" models. This ability makes AI better at answering hard questions. It isn't free. Let’s see how this works.

Step 1: What is thinking?

With thinking turned on, the AI first talks to itself, working through the problem out loud. Reasoning allows the AI to consider multiple options and catch its own mistakes. After it finishes thinking, it outputs an answer. Pick a question, then see how the output changes when thinking is turned on and off:

Step 2: Set the reasoning level

You can adjust how much the AI thinks. In a chat app there is often an effort level setting (low, medium, high) or a “think longer” option. Sometimes it's possible to set a thinking budget, which is a cap on how many thinking tokens the AI is allowed to use. Try the levels:

Pick a level.

The values shown for each level are just examples to illustrate the idea.

Why this matters

Pricing: The total cost is calculated by adding the cost of the thinking tokens to the cost of the input tokens and the cost of the answer (output) tokens. Even if you don't see the thinking tokens, you still pay for them. Currently, the thinking text is not included in the chat history, but this may change in the future.

Speed: When thinking is turned on, you will have to wait longer for an answer.

Use it for hard questions. Thinking helps most with complex problems like math, coding and rendering 3D worlds.

It’s not a guarantee. Thinking makes a correct answer more likely, but the AI can still be wrong.
